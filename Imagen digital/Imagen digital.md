# GIMP

<img width="1280" height="720" alt="image" src="https://github.com/user-attachments/assets/b6632100-667c-410a-915f-9d96434dde6e" />

GIMP es un programa de edición de imágenes digitales, gratuito y de código abierto. Se utiliza principalmente para retocar fotografías, crear diseños y modificar imágenes. Es una alternativa gratuita a otros programas de edición gratis y fiable, como Adobe Photoshop. GIMP permite muchas funciones, como recortar imágenes, cambiar su tamaño, modificar los colores, ajustar el brillo y el contraste, eliminar fondos y añadir textos o efectos especiales .Una de sus características más importantes es que trabaja con capas, que permiten editar diferentes partes de una imagen por separado sin modificar el resto. También dispone de muchas herramientas y filtros que facilitan la edición y la creación de imágenes. Este programa puede utilizarse tanto para trabajos sencillos, como mejorar una fotografía, como para proyectos más elaborados, como crear carteles, logotipos o dibujos digitales .Además, GIMP es compatible con diferentes formatos de imagen, como JPG, PNG y GIF, y está disponible para varios sistemas operativos, como Windows y Linux.
